Diff 对比

Diff 现在除了保持组合式结构，还补上一套更顺手的快捷 API。可以直接传内容和位置值，也可以用Diff.Item1、Diff.Item2、Diff.Resizer自己拼装。

何时使用

  • 需要比较两个版本、两套视觉稿或两段内容，并让用户自己拖动查看差异。
  • 想要一个更轻的 API，直接传左右内容和默认位置，而不是每次都手写三段结构。

# 增强写法

直接用 item1、item2、item1Label、item2Label 和 resizerContent 就能得到可拖动的对比区域。

快捷模式下内部会自动生成拖动层，键盘聚焦后也能直接调整位置。

# 受控位置

value 和 onChange 可以把 Diff 变成受控组件，适合和外部滑杆、表单或讲解步骤联动。

FAQ

快捷模式和组合式模式怎么选？

如果你只是想比较两个内容块，优先用item1和item2。如果你已经有现成结构， 或者需要完全接管内部节点顺序，就可以用组合式写法。

value 和 defaultValue 有什么区别？

value是受控值，外部状态说了算；defaultValue 只决定初始位置，之后由组件内部维护。

传了 children 之后 value 还会生效吗？

当前组件里，children会切换到组合式模式，因此value、defaultValue这些快捷模式能力不会接管内部布局。需要受控拖动时，优先使用item1/ item2。
