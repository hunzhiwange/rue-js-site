Range Slider 范围选择

Range 仍然坚持原生 input type="range" 的语义，但不再只是一条裸滑杆。现在可以直接在组件层补充标题、提示、刻度、值展示和语义回调，设计页也按能力分层重新组织。

# Range

展示最小写法；如果你只想要一个原生滑杆，API 仍然保持直接。

# API

不做增强展示时，Range 仍然是一个直接透传原生属性的滑杆；一旦传入 label、 showValue、marks 等属性，就会自动切换到更完整的展示结构。
