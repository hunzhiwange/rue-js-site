Chat bubble 聊天气泡

Chat 现在不再只是对 daisyUI 静态结构的薄封装。你可以使用 Chat.Bubble 这一套复合子组件，也可以直接通过 message、author、timestamp、avatar与 items 组织整条消息流。

Capability
单条消息语义化

根节点直接支持 message、author、timestamp、avatar 与 footer，不必先手写所有子结构。

Capability
items 数据驱动

items 支持 key、avatar 配置对象、typing、bubbleClassName 与别名字段，适合消息流。

Capability
复合组件保持

Chat.Bubble、Chat.Header、Chat.Footer、Chat.Image 仍然存在。

Capability
Typing 与快捷头像

Chat.Bubble 和 Chat 本体都能声明 typing；Chat.Image 也支持 src 快捷写法。

# 语义化单条消息

根节点直接描述一条消息：头像、作者、时间、正文与脚注都可以作为 props 传入。

# Typing 与自定义头像

typing 可以直接挂在 Chat 或 Chat.Bubble 上；avatar 配置对象适合放团队缩写、状态徽记或品牌头像。

# Chat items 作为消息流

items 适合后台消息中心、智能助手对话和审批日志，支持 key、typing 与 avatar 配置对象。

API

Chat 现在分成三层心智：根节点的消息语义 props、items 的数据驱动消息流，以及复合子组件的局部结构控制。

Chat Props

属性说明类型默认值
author / headerName单条消息的作者名别名，若未传 header 则会和时间一起自动组装头部。any-
avatar头像节点或配置对象；可直接传入自定义内容、src、alt 与 bodyClassName。any | ChatAvatarConfig-
avatarSrc / imageSrc头像图片地址别名；不再需要手写 Chat.Image 的内部结构。string-
bubbleClassName仅追加到 chat-bubble 的类名。string-
children提供组合式用法，可继续手写 Chat.Bubble、Chat.Header 等子结构。any-
className追加到当前 chat 根节点；items 模式下会透传给每一项。string-
color消息气泡颜色，会映射到 chat-bubble-* 语义类。'neutral' | 'primary' | 'secondary' | 'accent' | 'info' | 'success' | 'warning' | 'error'-
footer / footerClassName消息脚注与脚注区域类名。any / string-
header / headerClassName整块头部内容与头部区域类名；设置后优先级高于 author 与 timestamp。any / string-
items数据驱动入口，适合渲染完整消息流。ReadonlyArray<ChatDataItem>-

placement消息朝向，控制 start 与 end 布局。'start' | 'end''start'
timestamp / headerTime消息时间别名，自动包裹为 time 元素。any-
typing / typingIndicator开启 typing 态，或用自定义节点替换默认 loading dots。boolean / anyfalse / -
