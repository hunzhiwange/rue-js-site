Popover 气泡卡片

Popover 用来承载比 Tooltip 更完整的信息块和轻操作。Rue 实现采用当前的轻卡片视觉， 同时补充 title、content、overlay、触发方式、 定位、箭头和受控开合等核心能力。

它更适合字段解释、快速状态卡、内联操作和轻量二次确认，而不是用 Modal 打断页面流程。

# Basic popovers

# Placement

Top start
适合贴着触发器左边缘展示信息。
Bottom end
右下角常用来对齐工具条末端。
Left top
适合桌面端列表或表格中的侧向说明。
Right bottom
在工具面板、筛选块里会更自然。

# Trigger modes

默认 hover
鼠标进入时展示，移出后收起。
Click trigger
再次点击同一个触发器即可关闭。
Context menu
右键适合承载次级命令或辅助说明。
Focus trigger
适合输入前的字段说明与校验前置提示。
