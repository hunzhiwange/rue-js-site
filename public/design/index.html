Button 按钮

type负责视觉类型，color负责主题色，再用shape、icon、loading补足交互细节。

何时使用

  • 需要一个通用操作按钮，并希望颜色、类型、形状和状态能拆开表达。
  • 需要在表单里区分视觉类型type和原生提交类型htmlType。
  • 需要统一处理图标按钮、加载按钮、链接按钮和整行按钮。

FAQ

为什么有 type 还需要 htmlType？

type负责按钮视觉类型，htmlType负责原生 button 行为。视觉和提交语义拆开之后， 表单场景会更直接。

type 和 color 应该怎么分工？

type负责视觉类型，比如outlined、filled、text。color负责主题色，比如primary、secondary、danger。

大多数场景可以先定颜色， 再根据密度和层级选择solid、outlined、filled或text。

loading 对象里的 delay 会生效吗？

当前组件支持loading的对象写法和自定义icon。delay字段已保持在配置结构里，后续如果补充延迟显示策略，可以直接在当前接口上继续扩展。

Button.Group 会覆盖子按钮哪些属性？

组级只会统一同步size和shape，方便在一组按钮上集中控制尺寸和轮廓。 每个子按钮自己的color、type、disabled、onClick仍然在各自的 Button上配置。
