Carousel 跑马灯

Rue 的 Carousel 现在兼顾两类能力：一类使用 daisyUI 的滚动式视觉布局，保持多宽度、垂直、full-bleed 这些基础示例；另一类提供了成熟轮播组件常见的 arrows、dots、fade、dotPlacement 与方法控制。

Layout
使用 Rue 基础滚动感

`align`、`direction`、宽度类与 full-bleed 布局仍可直接复用。

Control
补充 dots / arrows / methods

支持 built-in arrows、dot placement、`apiRef` 方法与外部按钮编排。

Effects
Fade 与 progress dots

既能做内容轮播，也能做更偏产品展示或运营 banner 的切换样式。

API

属性说明类型默认值
align控制 scrollx 模式下当前 slide 的对齐方式`start` | `center` | `end``start`
direction切换水平或垂直布局`horizontal` | `vertical``horizontal`
effect切换滚动或淡入淡出效果`scrollx` | `fade``scrollx`
arrows显示内置切换箭头booleanfalse
dots显示分页 dots；对象形态支持附加 classNameboolean | { className?: string }false
dotPlacement控制 dots 在上、下、起始侧或结束侧的位置`top` | `bottom` | `start` | `end``bottom`
auto / autoplay开启自动播放；`autoplay={{ dotDuration: true }}` 会显示进度 dotsboolean | { dotDuration?: boolean }false
autoplaySpeed / interval控制自动播放节奏，保持 `interval` 写法number3000
autoDirection控制自动播放方向`forward` | `backward``forward`
activeIndex / initialSlide指定初始展示 slide；推荐外部联动时配合 `apiRef` 使用number0
