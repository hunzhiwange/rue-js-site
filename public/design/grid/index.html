Grid 栅格

Grid 提供接近成熟组件库的 24 栅格 API，用来组织页面骨架、卡片矩阵和左右混排布局。

视觉上使用 Rue 当前的轻量表面体系，能力覆盖 Row / Col、响应式断点、gutter、偏移、 顺序和 flex 混排。

# API

默认导出的 Grid 可直接当作 Row 使用，也可以通过 Grid.Row / Grid.Col 显式书写。

Grid / Grid.Row

属性说明类型默认值
gutter栅格间距，支持单值、[水平, 垂直]，以及按断点配置的对象写法number | string | ResponsiveValue | [ResponsiveValue, ResponsiveValue]-
justify主轴对齐方式，覆盖常见的 start / center / end / evenly 语义'start' | 'end' | 'center' | 'space-around' | 'space-between' | 'space-evenly'start
align交叉轴对齐方式'top' | 'middle' | 'bottom' | 'stretch'top
wrap是否允许自动换行booleantrue
className / style根节点样式扩展，使用 Rue 一贯的 class 直连能力string / Record<string, any>-

Grid.Col

属性说明类型默认值
span24 栅格占位数，0 表示隐藏当前列number-
offset在当前列左侧追加空白栅格number0
order通过 flex order 调整显示顺序number-
push / pull相对当前列原位向右或向左推移指定栅格数number0
flex支持 number、固定宽度字符串、auto 和 none，用于混合弹性布局number | string-
xs ~ xxl断点覆盖，支持直接传 span 数值，或传入包含 span / order / offset / push / pull / flex 的对象number | { span?: number; order?: number; offset?: number; push?: number; pull?: number; flex?: number | string }-
className / style列节点样式扩展string / Record<string, any>-
