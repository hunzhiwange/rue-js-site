Calendar 日历

Calendar 现在同时覆盖 Rue 原生月历面板、事项渲染、卡片式日历，以及 Cally、Pikaday 两条基础接入链路。

Native Panel

Month / Year 两种面板

新增默认 Calendar 面板，支持 value、mode、validRange、showWeek 与 headerRender。

Render Hooks

细胞级渲染能力

cellRender 和 fullCellRender 可以把普通日期格组织为事项列表、容量卡或数据看板。

Composition Ready

基础场景完整覆盖

Calendar.Cally、Calendar.Month、Calendar.PikaSingle 仍然可用，基础接入方式不需要拆。

默认面板，覆盖受控日期、范围限制、禁用规则与周序号。

# Notice calendar

使用 cellRender 在日期格展示事项，在年视图展示月份 backlog。

Preview

事项日历会在页面显示后自动初始化，不再需要手动点击加载。

# Card mode

缩成仪表盘卡片，再用 fullCellRender 为少量日期挂上负载进度。

Preview

卡片模式会在后台分帧挂载，避免首屏一次性把多个重预览一起算完。

# Custom header

接管顶部工具条，自定义模式切换、年份与月份选择器。

Preview

自定义头部示例会在页面稳定后自动挂载，减少首屏阻塞。

# Cally calendar example

基础的 Cally web component 日历壳层仍然原样可用。

Preview

Cally 预览会延后挂载，避免阻塞第一个日历示例。

# Cally date picker example

基础的日期输入弹层示例 展示，只把交互说明和布局重新编排。

Preview

# Pikaday input example

展示基础 pika-single 输入壳层，让第三方实例继续挂载在 Rue 组件树里。

Preview

API

默认 Calendar 面板聚焦于日历组件常见的核心交互能力，同时使用 Rue 自己的视觉和基础导出方式。

属性说明类型默认值
cellRender按日期格或月份格补充内容，适合放日程列表、状态徽标等轻量信息(date: Date, info) => any-
defaultValue非受控模式下的初始日期Date | string | numbernew Date()
disabledDate禁用特定日期；会同时影响日期格、月份导航与年份导航(date: Date) => boolean-
fullscreen切换为大面板或卡片模式booleantrue
fullCellRender完全接管单元格内容，适合 KPI、容量卡片等更强视觉定制(date: Date, info) => any-
headerRender自定义头部，拿到年/月选项与模式切换方法(config) => any-
mode视图模式，可在月视图与年视图之间切换'month' | 'year''month'
onRenderProfile渲染诊断回调，报告当前更新阶段、耗时、cellRender 调用次数与慢单元格(event: CalendarRenderProfileEvent) => void-
renderProfileThreshold渲染诊断的慢调用阈值，超过后会在 onRenderProfile 中标记 slownumber16
showWeek月视图下显示 ISO 周序号，适合排班和周计划看板booleanfalse

value受控日期；通常与 onChange、onPanelChange 搭配Date | string | number-
