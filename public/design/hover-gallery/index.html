Hover Gallery 悬浮画廊

Hover Gallery 适合做商品多视角缩略图。组件把多图预览结构收口成稳定 API：既能直接写children，也能切到items 数据驱动，并把导览遮罩和图片层样式统一收口到组件里。

何时使用

  • 需要在商品卡片、作品集卡片里，用最轻的结构承载多张预览图。
  • 想保持纯 CSS 的 hover 体验，但又不想在页面层重复写导览遮罩和图片映射逻辑。
  • 同一套页面里基础静态写法，也有列表数据驱动写法，希望 API 可以平滑共存。

# 数据驱动

items 支持字符串、对象项和自定义 node，方便从接口数据或内容配置直接渲染。

# 自定义导览与图片层

导览文案、导览样式和图片 object-fit 都能在组件层统一配置，不需要再在页面里手工叠 grid。
