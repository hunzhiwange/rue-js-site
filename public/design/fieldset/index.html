Fieldset 字段集

Fieldset 现在同时支持两类用法：展示基础的Fieldset.Legend/ Fieldset.Label组合写法，也补上更适合表单场景的结构化 props 与 Fieldset.Item。

何时使用

  • 需要把一组相关输入控件组织成一个明确的表单区块。
  • 需要同时表达标题、说明、字段提示、操作区和错误态。
  • 希望小表单走结构化 props，大表单展示基础 JSX 组合写法。

# 推荐写法

legend / description / items / hint / actions 适合直接搭表单区块。

description标题下方的说明文本any-
items数据驱动字段项，内部自动映射为 Fieldset.ItemReadonlyArray<FieldsetItemData>[]

hint底部提示文本any-
actions底部操作区，默认右对齐any-

推荐用法总结

legend + items适合直接搭一整块表单
Fieldset.Item适合沉淀复用字段行
children + Legend/Label支持基础写法
variant / tone / invalid用来表达区块层级和状态

FAQ

结构化 props 和 children 可以同时用吗？

当前组件里，children仍然是最高优先级。想走推荐写法时使用legend、description、items；想自由拼装时继续直接写 children。

什么时候该用 items，什么时候该用 Fieldset.Item？

简单表单优先用items，这样信息更集中；字段布局开始变复杂、需要横向排版或局部复用时， 更适合切到 Fieldset.Item。

variant 和手写 className 会冲突吗？

不会。variant只是给出一套推荐容器样式，仍然可以继续叠加当前的rounded-box、border、bg-*等类名做局部覆盖。
