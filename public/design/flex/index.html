Flex 弹性布局

Flex 为 Rue Design 补上一层语义化的弹性布局容器。它不为子元素额外包裹节点，展示className与style的直接组合方式，同时补充更完整的 的方向、对齐、换行、间距与伸缩能力。

JSX 代码标签现在展示完整示例 源码，去掉内部变换标记，复制后可以直接作为 Rue 组件起步。

查看 Flexbox 规范

何时使用

  • 需要一组块级元素在横向、纵向、换行和间距之间快速切换。
  • 希望直接控制 justify、align 和 flex，而不是在业务里手写整串原子类。
  • 需要使用 Rue 的轻量组合方式，同时使用更语义化的布局 API。

# 基础横向布局

默认是横向主轴和顶对齐，适合做概览卡片、摘要指标和信息排布。
