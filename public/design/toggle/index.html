Toggle 开关

Toggle 适合立即生效的双态切换。和 Checkbox 更偏向“标记后统一提交”不同，Toggle 更适合通知、同步、权限和偏好设置。

Rue 使用当前 toggle 视觉类，并提供了 Switch 常见的受控/非受控、状态文案、loading 和设置项布局能力。

API

属性说明类型默认值
checked受控选中状态boolean-
checkedChildren选中态展示内容，适合短文本或图标any-
children附加说明内容，传入后会自动包裹为设置项布局any-
color开关颜色主题'primary' | 'secondary' | 'accent' | 'neutral' | 'success' | 'warning' | 'info' | 'error'-
contentClassName设置项内容容器类名string-
defaultChecked非受控初始选中状态booleanfalse
defaultValue别名；传 boolean 时等价于 defaultChecked，传 string 或 number 时作为原生默认值boolean | string | number-
disabled禁用开关booleanfalse
loading加载态，同时自动禁用当前开关booleanfalse
onChange状态变化时回调，签名为 (checked, event)(checked: boolean, event: Event) => void-
onCheckedChange语义化别名回调，签名同 onChange(checked: boolean, event: Event) => void-
onClick点击开关时回调，签名为 (checked, event)(checked: boolean, event: Event) => void-
rootClassName设置项根容器类名string-
size尺寸，支持 xs 到 xl，也支持 small、default、medium 语义别名'xs' | 'sm' | 'md' | 'lg' | 'xl' | 'small' | 'default' | 'medium'-
stateClassName状态文案区域类名string-
unCheckedChildren未选中态展示内容any-
value别名；传 boolean 时等价于 checked，传 string 或 number 时作为原生 input 值boolean | string | number-
