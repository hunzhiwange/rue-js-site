Countdown 倒计时

现在既能可以使用 `Countdown.Value` / `items` 进行静态拼装，也能直接传入目标时间并通过 `format`、`onChange`、`onFinish` 驱动完整倒计时。

# Target Time Countdown

直接传入目标时间戳与 format，组件内部自动计算剩余时间。

::

# Millisecond Precision

包含 S 时会自动切到更高频率刷新，适合展示毫秒级结尾。

:::

# Day Level Format

支持把单位文字写进 format，并自动拆成数字段与纯文本分隔符。

 days  hours  minutes  seconds

# Callbacks

onChange 返回剩余毫秒数，onFinish 只在归零时触发一次。

.
最近一次 onChange: 10000 ms
onFinish 状态: 计时中

API

属性说明类型默认值
className追加到 Rue countdown 根节点的视觉类名。string-
value目标时间戳、Date 或可解析时间字符串；传入后启用自动倒计时模式。number | string | Date-
format按常见倒计时组件的格式拆分时间段，支持 `[]` 保持字面量。stringHH:mm:ss
interval自定义刷新间隔；含毫秒位时默认约 33ms，否则默认 1000ms。numberauto
ariaLive控制自动倒计时模式下每个数值段的播报策略。'polite' | 'off' | 'assertive'秒级 polite，毫秒 off
onChange自动倒计时每次刷新时返回剩余毫秒数。(remaining?: number) => void-
onFinish倒计时归零时触发一次。() => void-
items数据驱动的文本/数值混合渲染，适合完全自定义排布。CountdownItem[]-
