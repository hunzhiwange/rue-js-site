Empty 空状态

Empty 用来承接列表、筛选、面板和工作流中的无数据状态。它保持了 Rue 一贯的轻量卡片语言，同时提供了空状态组件最核心的 image、description、children 和预设插画能力。

组件提供可复用的空态表达：默认插画适合页面主体，simple 插画适合嵌入式空态，语义插槽则方便你在卡片、筛选器、列表面板里继续细调样式。

# 基础空状态

默认插画、文案和动作区已经能覆盖大多数页面级空态。

当前筛选条件下还没有上线中的条目。你可以放宽条件，或者直接创建新内容。

# 预设插画与变体

default 与 simple 两套预设插画覆盖页面主空态和紧凑容器；surface、soft、outline 对应不同层级。

默认插画适合页面主体空态。
简洁插画适合表格、筛选或紧凑容器。
outline 更适合嵌入次级区域。

# 自定义插画与左对齐布局

需要更贴近业务语义时，可以直接传自定义节点，并切到 start 布局承接更多说明。

# 嵌入式空态与语义插槽

classNames 和 styles 让 empty 可以自然嵌进列表、筛选面板和卡片，而不需要额外包一层 if。

API

保持易接入的属性组织方式，同时补一层更贴近 Rue 页面编排的尺寸、变体和语义插槽。

属性说明类型默认值
image空状态插画，支持字符串地址、预设插画组件函数或任意 JSX 节点。string | FC | anyEmpty.PRESENTED_IMAGE_DEFAULT
description文案区，可传字符串、富文本节点；显式传 false / null 可隐藏。any暂无数据
children底部动作区，适合放按钮、链接、过滤器重置等后续动作。any-
imageStyle / imageAlt控制插画容器样式与 img 的 alt 文案，支持字符串图片场景。any / string- / empty
size统一调整容器、插画与文案尺度，支持 sm / md / lg 及 small / default / large 别名。'sm' | 'md' | 'lg' | 'small' | 'default' | 'large'md
align内容布局方向，支持居中空态和左对齐嵌入式空态。'center' | 'start'center
variantRue 风格表面层级，适合页面主空态、嵌入卡片与轻量占位区。'surface' | 'soft' | 'outline'surface
className / rootClassName / style根节点扩展类名和样式，rootClassName 便于支持项目代码中的根节点类名分工。string / string / any-
classNames / styles语义插槽扩展，覆盖 root、image、description、footer 四个区域。object / object-
