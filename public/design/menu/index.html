Menu 菜单

Menu 用于垂直或水平展示导航链接。它同时支持组合静态结构，以及 `items / selectedKeys / openKeys / group / divider / extra` 等数据驱动 API。

API

`Menu.Item` 内置了常用链接能力，导航跳转示例里出现的 `to`、`href`、`target` 等属性可直接用于菜单项。

Menu.Item 链接相关

属性说明类型默认值
as指定交互节点类型；传入 to / href 时通常保持默认 a，纯动作项可改成 button 或 span。'a' | 'button' | 'span''a'
href外链或普通锚点地址；存在 href 且未传 to 时渲染原生 a 标签。string-
toRue Router 路由地址；传入后渲染 RouterLink，适合站内导航菜单。string-
target / rel外链透传属性；target="_blank" 且未传 rel 时，会自动补上安全的 rel。string-
title透传到交互节点的 title，适合长文案或补充说明。string-
disabled禁用点击与导航；会移除 href / to 的实际跳转并输出 aria-disabled。booleanfalse
onClick点击回调；可与 href / to 共用，也可配合 preventDefault 自定义拦截逻辑。(event: MouseEvent) => void-
icon / extra菜单项前置图标与右侧补充内容，适合链接导航里展示状态、快捷键或徽标。any-
