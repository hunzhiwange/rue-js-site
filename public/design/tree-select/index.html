TreeSelect 树选择

TreeSelect 适合“下拉选择 + 树结构浏览”同时存在的输入场景，比如目录、组织架构、权限树、资源分类和发布范围。 视觉使用 Rue 的 input / badge / base 色阶体系，能力覆盖 treeData、simple mode、多选、 勾选、语义值、异步加载和 filled / warning 等核心场景。

基础能力

先把单选、搜索和清空打稳，再把 simple mode、多选与勾选这些更接近业务配置面的能力接进来。

# Basic

单选、搜索、默认展开与 allowClear 的组合，是目录选择最常见的入口。

# Without allowClear

未开启 allowClear 时，只保持选择交互，不显示 selector 右侧的清空入口。

# Simple Mode

扁平树数据直接接入，适合后端给的是 id / pId 结构时减少前置整理成本。

Workflow board
当前目标：workflow
这类接口在 CMS、流程平台、低代码配置里很常见。只要给出 id / pId / value / title 映射，就能直接恢复成可搜索树。

# Multiple

多选模式默认以标签回填，适合通知订阅、面板订阅、资源批量绑定。

分析订阅会议纪要
已选：analytics / minutes

# Checkable

勾选树会把多选语义进一步贴近权限树和发布范围；默认 SHOW_CHILD 会直接回填实际勾选的子节点。

构建链路质量门禁
回填：build / quality
  • 策略当前示例使用默认 SHOW_CHILD，选了哪些子节点就回填哪些子节点，更适合精确范围选择。
  • 切换如果业务更想要紧凑展示，可以把 showCheckedStrategy 改成 TreeSelect.SHOW_PARENT，让完整分组选中时折叠成父标签。
  • 回填当前示例最多展示两个标签，更多已选项会用 ... 收起，避免 selector 被撑成两排。

高级能力

语义值、异步加载和外观变体覆盖配置类面板里的常见选择场景。

# Label In Value

当业务既要 value 也要 label 时，直接回填结构体会更顺手。

# Async Load

展开未加载分支时触发 loadData，适合远端目录、权限树和超大分类树。
