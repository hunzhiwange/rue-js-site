Layout 布局

Layout 用于组织页面骨架、双栏工作台、可折叠侧栏和响应式 rail。API 覆盖 Layout / Sider 这组核心能力，视觉仍然使用 Rue 当前的柔和面板、圆角和 utility class 组合方式。

何时使用

  • 需要把导航、工作区、补充信息区和页脚组织成稳定的页面骨架。
  • 需要一套既能做控制台类双栏壳子，也能做 dashboard 内部嵌套布局的基础容器。
  • 需要侧栏支持收起、零宽触发器和响应式 breakpoint，而不是自己拼一层 Flex 状态机。

API

Layout 的目标不是替代 Flex，而是把页面级骨架和带状态的 Sider 收敛成一套更稳定的基础设施。 如果只是做局部排版，可以用 Flex / Grid；如果要组织页面结构、导航和补充侧栏，就切到 Layout。

属性说明类型默认值
hasSider显式声明当前 Layout 包含 Sider，适合 SSR 或异步 children 场景避免首帧方向抖动。boolean自动推断
className / style根容器样式扩展，继续保持 Rue 的 utility class 叠加方式。string / string | Record<string, any>-
Layout.Header / Content / Footer语义分区子组件，默认提供 Rue 风格的面板样式，也支持通过 className 覆盖。FC-
Layout.Sider侧边栏子组件，支持折叠、响应式收起、零宽触发器和自定义 trigger。FC-
Sider.width展开态宽度，支持数字与任意 CSS 长度。number | string240
Sider.collapsedWidth收起态宽度；传 0 时会切到零宽模式，保持浮动 trigger。number | string80
Sider.collapsible开启点击触发器的折叠能力。booleanfalse
Sider.collapsed / defaultCollapsed受控和非受控折叠态。booleanfalse
Sider.breakpoint按 xs 到 xxl 断点自动切换 broken / collapsed，并触发回调。'xs' | 'sm' | 'md' | 'lg' | 'xl' | 'xxl'-
Sider.trigger自定义 trigger 节点，或传入函数读取 collapsed / below / zeroWidth / toggle。any | (meta) => any内置 Trigger
Sider.triggerPosition控制默认 trigger 贴在起始侧还是结束侧。'start' | 'end'end
Sider.theme切换 light / dark 两套侧栏基底色。'light' | 'dark'light
Sider.onCollapse / onBreakpoint监听点击折叠与响应式断点变化。(collapsed, type) => void / (broken) => void-
