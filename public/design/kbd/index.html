Kbd 键盘提示

Kbd 可以使用 Rue 当前的键帽视觉风格，并补上更适合实际场景的组合键 API。现在既可以写 <Kbd>K</Kbd> ，也可以直接用items或Kbd.Group组织快捷键序列。

何时使用

  • 需要展示单个按键、组合键或快捷键列表。
  • 希望可以使用 Rue 当前键帽视觉，但让组合表达更语义化、更容易复用。
  • 需要在设计页里同时保持静态示例和更贴近真实产品的快捷键场景。

API

当前页面展示的是 Kbd 根组件与组合模式的完整可用 API。

复合子组件

Kbd.Combo：显式渲染组合键序列，适合控制separator、wrap和itemClassName。
Kbd.Group：显式渲染布局容器，适合用direction和 gap组织多条快捷键。
Kbd.Separator：默认输出带弱化样式的分隔符，内容默认是+，也可以换成/、then等文案。

FAQ

什么时候用 children，什么时候用 items？

单个键帽或完全自定义布局时，可以用children 最直接；需要表达标准组合键时，优先用items或Kbd.Combo，维护成本更低。

分隔符只能是加号吗？

不是。你可以通过separator传任意节点，也可以直接使用 Kbd.Separator包一层，统一保持当前页面的弱化分隔视觉。

完整键盘这种自由布局还支持吗？

支持。Kbd 本质上仍然是轻量键帽组件，语义 API 只是补充组合键表达，不会限制你自由排布完整键盘。
