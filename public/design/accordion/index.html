Accordion 手风琴

Accordion 现在使用 Rue 基础的轻量视觉风格，但 API 不再只是静态包装。你可以用 Accordion.Title和Accordion.Content 组合单个面板，也可以直接用 items 走数据驱动，接入受控 key、多开、禁用和富标题信息。

何时使用

  • 需要 FAQ、设置说明、任务面板这类“标题 + 可折叠内容”的信息组织方式。
  • 需要在单开和多开之间切换，或把当前展开项接到页面状态里。
  • 需要在标题里补充状态、说明、标签，而不想为每个面板手写结构。
  • 需要让浏览器能搜索折叠内容时，使用 use="details"。
Capability
Children 组合

保持 Accordion.Title / Accordion.Content，用于局部定制标题和内容。

Capability
Items 驱动

直接用 items 写标题、描述、额外信息和禁用态，适合后台配置页。

Capability
受控状态

通过 activeKey、openKeys、onChange 接管当前展开项。

Capability
两种语义

默认 radio 风格适合单开；details 适合保持可搜索内容与原生语义。

Single but collapsible

不想强制保持一个展开项时，可以给 children 模式加 collapsible。

Can I close the last open panel?
Yes. Set collapsible to allow toggling the current panel off instead of forcing one active item.

API

Accordion 现在分成两套用法：children 模式适合局部排版，items 模式适合数据驱动和受控状态。 两套模式共用同一套视觉类名，因此重组示例时通常只需要把结构收敛到更清晰的语义层。
