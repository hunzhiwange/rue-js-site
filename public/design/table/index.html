Table 表格

Rue Table 现在同时覆盖数据驱动表格和 daisyUI 风格的静态表格写法，使用 Rue 当前视觉风格，并补充更完整的 排序、筛选、分页、选择、展开与分组表头能力。

可以先从基础用法进入，再根据场景查看筛选排序、选择模式、滚动布局与分组表头。静态样式写法仍然提供，可继续 使用Table.Head、Table.Body等复合组件。

何时使用

  • 需要展示结构化列表数据，并同时提供排序、筛选、分页等交互。
  • 适合使用 Rue / daisyUI 的表格视觉风格，同时使用数据表式 API。
  • 基础简单静态表格，也有复杂后台表格，想统一在一个组件里处理。

FAQ

数据驱动和静态结构怎么选？

需要排序、筛选、分页、选择、展开时优先使用columns + dataSource。只想快速输出结构化样式， 或需要完全手写表格结构时，可以使用复合组件写法即可。

为什么筛选或排序后会回到第一页？

这是为了避免当前页在筛选后没有数据。如果你希望完全自行控制分页，把 pagination.current和onChange一起受控即可。

固定列和 pinCols 的关系是什么？

pinCols负责启用 daisyUI 的固定列视觉能力，具体哪一列固定则由列上的 fixedCol或fixed控制。静态结构写法中，通常把固定列单元格写成 TH会更自然。
