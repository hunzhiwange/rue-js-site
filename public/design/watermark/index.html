Watermark 水印

Rue 的 Watermark 不照搬其他组件库的视觉，而是把能力落成更适合当前设计站点的轻量覆盖层。 你可以直接给任意容器加文字或图片水印，同时保持按钮、卡片、统计区这些内容本身的交互。

何时使用

  • 需要给卡片、报表、详情页加上“内部预览”“草稿”“仅限共享”等视觉标记。
  • 需要图片或文字水印覆盖在任意内容上，但又不希望阻断按钮、链接和表单的交互。
  • 需要局部容器继承上层水印图案，而不是为每一块内容重复写一遍配置。

# Image watermark

图片模式适合品牌 logo、部门印记或业务章；Rue 这边建议把它用在局部容器，而不是整页满屏。

# Inherited local scope

父级配置一次，子级局部容器可以继续复用；不想继承时再显式关掉。

继承父级水印

这个局部容器没有重新写 content 和 image，会直接复用外层图案与铺设参数。

关闭继承

当局部容器不需要上层水印时，直接把 inherit 设为 false 即可回到纯净内容区。

API

属性说明类型默认值
content文字水印内容，支持字符串或多行数组。string | string[]-
image图片水印地址，适合 logo、签章、业务标记。string-
font文字水印的颜色、字号、字重、字体和对齐方式。{ color?: string; fontSize?: number | string; fontWeight?: number | string; fontStyle?: string; fontFamily?: string; textAlign?: string }{ color: 自动按宿主背景明暗推导, fontSize: 16 }
rotate单个水印块的旋转角度。number-22
width / height单个水印内容块的尺寸；不传时文本会按内容估算。number文本自动测量 / 图片 120 x 64
gap水印块之间的水平与垂直间距。[number, number][100, 100]
offset起始铺设偏移量，便于与卡片头部或图像对齐。[number, number][gapX / 2, gapY / 2]
zIndex覆盖层层级，保持视觉上方但不阻断交互。number9

className / rootClassName根容器类名，便于直接叠加 Rue 的布局与视觉类。string-
overlayClassName / overlayStyle覆盖层类名和样式，适合与圆角、混合模式、局部调优配合。string / any-
