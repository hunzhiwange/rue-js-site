Mockup Code 代码外框

MockupCode 现在同时支持两种写法：展示基础 pre + data-prefix 结构，也提供更顺手的 items 与 MockupCode.Line 语义 API，适合终端日志、代码片段和差异对比。

何时使用

  • 需要用 Rue 的终端外框包裹一小段安装命令、日志输出或代码片段。
  • 希望把行号、前缀、状态色和高亮行用语义属性表达，而不是手写每个 pre。

# 推荐：items 数据驱动

适合命令日志场景，根节点 prefix 可给整组行提供默认前缀。

pnpm add @rue-js/design
Resolving workspace packages...
Done in 2.1s

# 组合子项

需要混合前缀、原生节点和 highlight 时，用 MockupCode.Line 会更直观。

import { MockupCode } from '@rue-js/design'
const lines = [{ children: <code>hello rue</code> }]
<MockupCode items={lines} />

# 自动行号

当前示例先用显式前缀展示带行号片段，预览区可稳定看到完整内容。

import { MockupCode } from '@rue-js/design'
export default function Demo() {
  return <MockupCode lineNumbers items={lines} />
}

FAQ

什么时候用 items，什么时候可以写原生 pre？

如果内容来自数组、日志流或代码生成，优先用 items；如果你已经有现成的 pre + data-prefix 结构，继续透传即可，不需要额外改造。

highlight 和 tone 分别负责什么？

tone 负责语义色，适合成功、错误、告警等输出；highlight 负责行背景强调，两者叠加后更适合做 diff 或重点提示。
