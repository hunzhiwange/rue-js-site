Splitter 分割面板

Splitter 在 Rue 里不是一条简单的分隔线，而是一套适合工作台、配置台和双栏内容区的布局行为层。 它使用 Rue Design 当前的柔和卡片气质和 3px 分隔条视觉，同时补上可拖拽、受控尺寸、垂直布局、lazy 拖拽和双击重置这些常用能力。

何时使用

  • 需要左右或上下两个工作区同时存在，并允许用户按内容密度自己调节比例。
  • 需要把筛选区、编辑区、预览区、日志区这类不同角色的面板拆开，但仍保持同一个页面上下文。
  • 需要在布局层提供受控重置和 lazy 拖拽，而不是只做静态栅格分栏。

API

Splitter 的根组件负责布局和交互，所有真正参与计算的子节点都应该是 Splitter.Panel。 如果你在业务里需要把布局状态持久化，优先使用 size+onResize的受控写法；如果只需要默认占比，用defaultSize即可。

属性说明类型默认值
orientation / layout / vertical控制分割方向；推荐用 orientation，vertical 作为别名保持。'horizontal' | 'vertical' / boolean'horizontal'
lazy开启后拖拽期间只移动分隔柄，释放鼠标时才真正提交面板尺寸。booleanfalse
onResizeStart / onResize / onResizeEnd拖拽开始、拖拽中、拖拽结束的回调，统一返回当前所有面板尺寸。(sizes: number[]) => void-
onDraggerDoubleClick双击分隔柄时触发，适合和“重置布局”联动。(index: number) => void-
Splitter.Panel size受控尺寸，支持像素数值或百分比字符串。number | string-
Splitter.Panel defaultSize非受控初始尺寸，常用于两栏默认占比。number | string-
Splitter.Panel min / max限制面板最小值和最大值，防止拖拽过界。number | string-
Splitter.Panel resizable禁用相邻分隔柄的拖拽能力，但保持布局结构。booleantrue
