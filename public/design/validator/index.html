Validator 校验辅助

Validator 仍然只负责把浏览器原生校验结果映射成 Rue 当前的表单视觉，不引入额外校验引擎。基础的className="input validator"写法继续可用，但现在也可以直接通过appearance、size、status和Field组合件来组织更完整的表单场景。

原生校验优先
继续依赖 required、pattern、minLength 等原生约束。
语义外观补充
用 appearance 直接映射 input、select、toggle 等宿主风格。
表单结构复用
Field 统一 label、hint、extra 和基础可访问性连线。

# Hidden hint and rule list

API

Validator 本体负责控件本身的宿主类和状态类，Hint 管理提示文案，Field 则把常见表单项的结构和可访问性连线收敛到一处。

Validator

属性说明类型默认值
appearance自动补充 input、select、textarea、checkbox、toggle 这些宿主类名'input' | 'select' | 'textarea' | 'checkbox' | 'toggle'-
as指定渲染标签，select 和 textarea 会自动推断对应外观'input' | 'select' | 'textarea''input'
className追加自定义类名，基础写法仍可继续手动传入 input / select / textareastring-
size按宿主类型拼接尺寸类，例如 input-lg、checkbox-sm'xs' | 'sm' | 'md' | 'lg' | 'xl'-
status手动追加状态类，适合服务端校验或异步反馈场景'error' | 'success' | 'warning'-
